## 변경한 흐름

- 세계 10개국, 도시 탐험, 세계 수도를 선택할 수 있다. 빠른 프리셋의 기본 문제 수는 10개다.
- 수도 도전은 일반 도시 도전과 별도의 랭킹 조건을 사용한다.
- 프리셋 뒤에 문제 종류를 직접 변경하거나 같은 지역의 catalog가 갱신되어도 수동 선택을 덮어쓰지 않는다.
- 매 메뉴 시작마다 후보를 새로 섞고, 한 게임의 언어와 정답 정책은 고정한다.
- 이동 중 일시 정지 후 복귀, 판정 연출 중 탭 숨김, 오래된 지도 준비 이벤트를 방어한다.
- 수동 힌트와 정답 공개 후 넘기기, 방문 표시와 경로, 문제별 복습을 연결했다.
- 랭킹 시간에서 일시 정지를 제외한다. 이전 조회 응답이 최신 기록을 덮어쓰지 않는다.
- 브라우저 저장 공간 접근이 차단돼도 앱은 실행되며 저장 실패를 결과 화면에서 안내한다.
- 지도 연결에 실패하면 재시도하거나 로컬 국가 경계를 사용하는 간단 지도로 계속할 수 있다. 간단 지도는 3D·도로를 지원하지 않는다고 표시한다.
- 플레이 도중 3D 지도를 다시 연결할 때는 타이머를 일시 정지해 로딩 시간 때문에 점수를 잃지 않는다.

## 실제 3D 지도 검수

`scripts/inspect-experience.mjs`로 1440×900, 390×844에서 실제 hosted 지도를 실행했다. 테스트 지도나 짧은 테스트 타이머는 사용하지 않았다.

- 스타일: `https://tiles.openfreemap.org/styles/liberty` — 로드 성공.
- source: `ne2_shaded`, `openmaptiles`.
- globe projection 및 국가·지역·도시·도로·수계 스타일 레이어 확인.
- 3D 건물: `building-3d`, `openmaptiles/building`, 실제 `render_height`, 최소 zoom 14.
- DEM source 없음. terrain은 비활성.
- 두 화면 크기 모두 실제 국가 polygon 클릭으로 대한민국을 선택했다.
- 도시 3문제에서 일시 정지/복귀, 수동 힌트, 정답·오답 제출, 결과와 닉네임 저장을 확인했다.
- 두 크기 모두 콘솔 오류 0건, 가로 넘침 없음.
- 실제 화면에서 발견한 작은 HUD 글자, 남아 있던 hover tooltip, 섬마다 중복되던 국가 판정 라벨을 수정했다.

검수 이미지는 `docs/screenshots/experience/`의 world, korea-cities, city-question, result 파일에 desktop/mobile로 저장했다. 자동 E2E의 간단 지도 이미지는 실제 3D 품질 증거와 구분한다.

## 자동 검사

`npm run check`로 lint, TypeScript, 단위 테스트 175개(32개 파일), 지리 데이터 검증, production build가 통과했다. MapLibre의 지연 로딩 번들 크기 경고는 남아 있으며 빌드 오류는 아니다.

브라우저 회귀 검사는 깨끗한 Vite 서버에서 `CI=1` 환경으로 `npm run e2e -- --workers=1`을 실행했으며 데스크톱·모바일 18개가 모두 통과했다(1.5분). 언어·IME·랭킹 검사와 도시 플레이·복습·일시 정지·HTTP 503 간단 지도 복구 검사를 포함한다. Playwright는 다른 앱을 검사하는 일이 없도록 기존 포트의 서버를 재사용하지 않는다.

### 테스트 환경에서 발생한 실수

최초 실행은 4173 포트의 별도 `rupture-lab` 개발 서버를 재사용해 실패했다. 진단 중 해당 서버(PID 25300)를 잘못 종료했다. GeoType에서 시작한 서버가 아니었으며, 원래 실행 명령을 확인하지 못해 임의로 재시작하지 않았다. 이후 `reuseExistingServer: false`로 변경했으므로 포트 충돌 시 다른 앱을 검사하거나 종료하지 않고 명확히 실패한다.
